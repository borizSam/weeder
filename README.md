- [ ] **Galería de viajes** — cards con imagen, descripción, enlace al detalle y botón "Contratar viaje"

## Consejos para el Equipo

- **Paleta de colores:** tonos oscuros con acentos en verde neón, morado y azul para el rollo astral/psicodélico
- **Tipografía:** *Bangers* para títulos (estilo cómic) y *Nunito* para el cuerpo — ya instaladas desde Google Fonts
- **Wireframes:** antes de escribir código, dibujad en papel cómo debe quedar cada sección
- **Responsividad:** diseñad primero para móvil y luego ampliad para escritorio (*mobile-first*)
- **Git:** cada uno trabaja en su rama y hace Pull Request para fusionar los cambios
